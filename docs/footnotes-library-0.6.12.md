# 脚注与书库 0.6.12

版本19，compile/target36、min26；继续完善 EPUB/TXT 文字阅读。

## 脚注

带 `noteref`/`doc-noteref` 语义的链接，及同章指向明确 footnote/endnote 的链接，可就地打开脚注。支持当前章片段、跨文件和不在spine中的尾注，百分号编码路径按实际章节URL解析。普通链接继续使用原有跳转，不按文件名猜测脚注。

弹层在当前WebView的正文流外，用Shadow DOM隔离样式，继承正文当前字体、字号和主题。关闭按钮、遮罩及系统返回均不跳章节；旋转/重排关闭弹层，原文仍在原位。弹层触摸与选区不参与正文翻页、索引、高亮或全书页数。没有增加第三个WebView。

core复用既有受限XML解析器，原生IO提取目标或其语义脚注容器，按白名单重新输出段落、列表和强调等基本HTML，去除属性、活动内容、图像和回链。只允许书籍根目录内的资源，单个片段不超过32768字符；关闭、替换和销毁通过请求序号屏蔽过期结果。失败可关闭，spine目标可使用前往原文入口。

兼容目标是有结构语义的常规XHTML脚注；复杂数学、图像、交互内容、非规范HTML及依赖外部DTD的实体未新增兼容保证。语义依据见 [W3C EPUB词汇](https://www.w3.org/TR/epub-ssv-11/#sec-notes)。

## 书库

封面完整缩放至展示区域，底边对齐，阴影/圆角跟随实际图像边界；横版和狭长封面不再裁切。缺封面时保留占位书封，小尺寸占位调整文字大小。书卡整块可打开，选项单独保留，标题两行、作者一行及阅读状态统一显示。

继续阅读卡片用Android系统UI字体，突出书名和作者；正文各款字体不变。阅读状态显示真实章节及章内进度，PDF显示页号，未估算全书百分比。MainActivity的SaveableStateHolder保留书库标签、筛选、排序、网格/列表及滚动状态；最近阅读排序仍会按新的打开时间重排。

现有配色和布局沿用Apple书库组织方向，[Apple指南](https://support.apple.com/en-is/guide/iphone/iphab219b91/ios)支持网格/列表及藏书组织。本轮未取得同版本完整原版书库截图，不将尺寸、阴影和卡片参数描述为逐像素复刻。

## 验证

core新增4项先因接口缺失失败，实现后与原12项合计16项通过。脚注4项界面回归先失败，再验证同章、跨文件、非spine、系统返回、缺失提示、普通链接、快速关闭、重建、字体及正文/页数不变。

封面用例先复现宽高比应为2、实际被裁为0.666。书库状态测试先修正了导航选择器与去重测试数据；临时恢复旧版无状态保留实现后，确定性复现“退出阅读丢失书库标签”，恢复修复后两项通过（18.053s）。使用十本不同内容、稳定书名排序、长标题及横竖封面，验证列表和滚动恢复。独立整体代码审查未发现实质问题。

Core16项、JVM4项、Node手势输入4项及六份JavaScript语法检查通过，两种构建成功。Lint为0错误、23警告，本轮新增一条KTX写法建议。

# 阅读翻页推进记录 · 0.4.0

EPUB/TXT 阅读页新增“卷页”和“快速淡入淡出”，入口在“主题与设置 → 翻页样式”；连续滚动保留原有开关。参考 [Apple 官方 iPhone 阅读说明](https://support.apple.com/zh-cn/guide/iphone/-iphc1af7c57/ios) 中的翻页样式，Android 上的卷曲形变仍为近似实现。

## 本轮行为

- 一次横向滑动只前进或后退一个画面，不再与 WebView 自身横向滚动叠加。
- 向前跨章进入上一章末尾；首章与末章不会越界。
- 章节边界按实际剩余距离判断，修复超过 202 个画面的章节可能跳过首尾页面的问题。
- 翻页效果与滚动选择持久保存，已有滚动偏好兼容；系统关闭动画时直接完成翻页。
- 动画仅持有一张当前画面的临时快照，最多 200 万像素且不超过 1200×2000，结束、尺寸/设置变化或页面销毁时释放。
- 正文继续由原 WebView 提供，保留文本锚点、选择、高亮和 CSP；未增加依赖或应用权限。
- 回归修复 PDF 当前页判断：搜索跳页后，顶部若残留上一页片段，按可见面积最大的页面显示并保存页码，避免旧系统上仍显示上一页。

## 测试方法

新增设备测试覆盖真实 EPUB 的边缘点击、物理滑动、文字选择抑制翻页、双向章节边界、超长章节首尾可达、两种效果与偏好恢复、动画中实际 Activity 重建，以及系统关闭动画。动画截图将模拟器的系统动画速度临时设为三倍，完成后恢复原设置，便于检查中间帧；应用正常时长为卷页 420ms、淡入淡出 180ms，系统动画缩放仍然生效。

回归中一并修正测试的异步等待：正文出现后还需等待阅读引擎初始化；进度保存检查等待实际写入。动画中间帧使用主线程观察，避免 ActivityScenario.onActivity 自身等待 UI 空闲而错过整个动画。长章节夹具采用 420 个带分页高度的段落，以在手机与双栏平板上超过 202 个画面，避免为测试构造无必要的海量正文。

独立代码审查发现的长章节边界问题已先复现再修复。审查保留一项低优先级问题：滑动后 400ms 内的另一次独立点击可能被当作同一手势的合成点击忽略，后续继续微调。

## 当前限制

卷页在手势触发后播放，尚无手指跟随、中途取消回弹及跨章动画。当前以整个可见画面为翻页单位；平板双栏下翻动整个跨页画面。卷曲光影、纸张形变与原版界面仍需在原设备上逐页校准。PDF 继续使用原有逐页滚动与缩放路径。

完整对齐范围见 [对照清单](reference/parity.md)。

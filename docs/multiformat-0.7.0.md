# 0.7.0：复用开源解析能力，扩展电子书导入

版本码21；compile/target API36、min API26。新增MOBI、AZW、AZW3、FB2，和既有EPUB、PDF、TXT合为七种导入扩展名。AZW是封装扩展名，实际读取文件头验证MOBI/KF8；不能由扩展名保证内部格式可读。

## 整合方式

固定 [Foliate-js 78914aef](https://github.com/johnfactotum/foliate-js/tree/78914aef4466eb960965702401634c2cb348e9b1) 的MOBI/KF8、FB2解析模块和其fflate0.8.2模块。源文件逐字节核对上游Git blob，保留原文；开发期用esbuild0.25.12生成兼容Chromium69的单个离线脚本，普通Gradle构建不需要Node或网络。见[源码说明](../third_party/foliate-js/README.md)与[重建步骤](../tools/import-converter/README.md)。

新增格式在导入时启动临时本地WebView解析，输出章节、目录、内链、图片、样式和可用嵌入字体，再由有界Writer写成私有标准EPUB。保留原始文件、原格式标签和原始SHA256身份；同一文件去重。阅读时沿用现有界面与引擎，共用单/双栏分页、字号、字体、主题、搜索、高亮、笔记、书签、脚注与来源返回、位置恢复和翻页动效。

转换器不将书内HTML挂入运行页面，CSP及本地请求映射阻止脚本/外部页面执行；主动内容和外部资源移除。图片和字体落盘，目录/内链改为本地章节锚点，非线性注释不进入主阅读顺序。FB2二进制图片先转为共享Blob引用，避免反复序列化base64；输出前再本地化。样式表按链接用途识别CSS，保证通用二进制MIME不会使字体链接残留为临时Blob。

导入完成和书库落盘成功后才显示记录。取消、超时或保存失败清理中间目录；书库保存异常会回滚内存更新。阅读副本缺失可通过重新导入同一文件修复，保留原书记录、书签和笔记。已存在的EPUB/PDF/TXT数据不迁移。

## 支持边界

- MOBI7/KF8（含双格式文件）、未加密AZW/AZW3和FB2；不解密DRM，不支持KFX及Print Replica。
- 新转换格式原文件64MiB，正文文本32MiB（图片数据不计入），单资源/章节16MiB、总输出256MiB，最多2000章节、2000目录项、32层目录，转换60秒限时。原有格式的限制不变。
- MOBI解压记录、字典递归、表项和总文本都有提前检查；截断索引不可零进度循环，同时保留固定上游解码器原有整数容错行为。
- 这不是全格式/所有出版物排版完全等价的承诺。Word、RTF、漫画压缩包等未在本轮加入；没有进行实体设备耗电、峰值内存或长期阅读统计。

## 验证

核心16/16；JVM4/4；Node8/8（手势5、截断索引/兼容整数2、CSS字体本地化1）；七份浏览器脚本语法通过，转换脚本重建字节一致。常规/个人构建成功；lint0错误、24警告。

自建真实Palm数据库MOBI和FB2覆盖：中文、多个正文记录、各扩展名、原文件保留/移除、去重、UTF16、图片、嵌套目录、内链和非线性脚注、搜索与批注、分页/样式/进度恢复、DRM/错误封装/实体/大小拒绝、取消清理、索引保存回滚、阅读副本修复，以及25章共用一张1MiB图片。

另使用 [libmobi固定样本](https://github.com/bfabiszewski/libmobi/tree/906274205c11944b628da1c553b255acb1af7c55/tests/samples) 五本：`sample-obfuscated-fonts.mobi`、`sample-unicode-huffdic.mobi`、`sample-unicode-uncompressed.mobi`、`sample-cp1252.mobi`、`sample-ncx.mobi`。字体样本为真实KF8；HUFF、未压缩、NCX三本为双格式文件，其KF8段分别使用HUFF/CDIC（17480）、未压缩（1）与PalmDOC（2）。另有CP1252旧编码。样本只保存在本地`.tools`及测试设备，不随仓库/APK分发。实际阅读页验证了“Kurier Light”嵌入字体在转换器关闭后仍加载成功。

独立审阅的截断索引和重复图片问题均通过先RED后GREEN修复；追加的真实字体检查又发现通用MIME样式表未本地化问题，Node及真实KF8阅读页先失败后通过。索引保护最初过严，真实双格式HUFF样本将其复现；改为保留上游解码容错、检查越界和零进度，五本样本重新通过。

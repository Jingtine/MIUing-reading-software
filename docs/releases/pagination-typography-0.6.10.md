# 整本分页与中文排版 0.6.10

版本17，compile/target36、min26。此轮继续完善 EPUB/TXT 文字阅读，界面字体仍跟随 Android 系统。

## 阅读行为

分页模式逐章计算实际物理页数，计数完成后底部显示整本页码，进度滑块可以跨章节跳转。平板双栏显示页码范围，每栏算一页；末尾空白半栏不计入总页数，空章节保留一页。首次打开或重排期间明确显示本章范围，滚动模式也使用本章进度。菜单打开时固定范围，避免后台计数完成后滑块含义突然变化；松手才跳转，仍可返回来源位置。

主题自定义布局新增中文排版开关，默认关闭。开启后可调首行缩进0–3字、段间距0–1.5倍字号，初值2字和0.5倍字号，分别按主题保存。仅覆盖含汉字的普通段落，排除代码、列表、引文、表格、题注及居中/靠右段落。段落使用浏览器的 `line-break: strict` 和 `word-break: normal`，不是完整的专业中文排版引擎。关闭可准确恢复书籍原有行内样式；不插入空格、不改正文字符与锚点。

## 实现与边界

`ReadingLayout` 为正文、翻页预览及计数提供同一份布局配置，`BookPageMap` 单独负责页码与跳转映射。实际内容范围在布局变化后测量，翻页只读取缓存；双栏末页的滚动补齐元素放在正文流之外。字体和图片稳定后再发布页数，延迟图片加载会重新测量并恢复当前锚点。

后台逐章计数与卷页复用一个辅助 WebView，总计最多两个；前台交互优先，切后台暂停，不写阅读进度。每次计数有超时，失败保留本章范围。不可变缓存快照经共享锁和 AtomicFile 写盘，完成和退出时立即排队保存，快速重开不会读到尚未提交的旧状态。

缓存按书籍与布局隔离，每本保留最近8份布局。键包含字体、字号、窗口、排版、批注和渲染环境，也包含系统字体缩放、语言、密度及系统字体粗细设置；当前阅读位置与纯颜色不影响键。无效或损坏缓存重新计算，不编造总页数。仍以常规无 DRM、可重排版 EPUB 为兼容目标，未新增固定版式、竖排和交互 EPUB 支持，也未完成标点挤压和悬挂。实体设备帧时间、耗电和内存峰值尚未测量。

## 验证

新增实际 WebView 和阅读界面用例覆盖物理页边界、双栏奇数末页、空章节、延迟图片、中文原文与样式恢复、缓存损坏与退出保存、全书跳转与返回、后台暂停、交互优先及系统字体配置失效。独立代码审查发现的退出缓存丢失、延迟图片页数过期两处问题均先复现失败，再修复通过。另以回归用例验证未改变尺寸的界面回调不会中断快速连续拖动。

首轮矩阵又复现两处问题：旧系统同一时间戳下淘汰了刚写入缓存；资源已稳定后的重复锚点恢复移动了初始片段落点。现明确保留刚写入缓存，仅在资源尚未稳定时恢复资源重排后的锚点。平板定向定位、图片、主题与缓存13项全部通过（115.880s），随后完整矩阵全部重跑通过。测试工具同步适配无需滚动的平板设置面板；滑块输入改为有时长的连续移动，保留松手前不跳转及精确落点断言。

# 0.7.4 全书逐条文字搜索

文字结果由每章一条改为每次命中一条，显示章节/章内序号、匹配文字和前后上下文。选择后通过现有高亮定位；上一处/下一处可跨章节。连续查看只保留一个搜索来源，关闭搜索返回原文。输入关键词不会移动阅读页；旋转后保留当前定位并重建搜索结果。

参考并适配 [Foliate-js search.js](https://github.com/johnfactotum/foliate-js/blob/78914aef4466eb960965702401634c2cb348e9b1/search.js) 的 pre/match/post 摘录规则；固定为已有Foliate提交78914aef，MIT版权及修改说明见 `third_party/foliate-js/SEARCH-ADAPTATION.md`，原MIT许可随APK分发。也检查过jsoup，但本轮未添加第二套解析器或运行时依赖。

## 实现与限制

- 发现结果和实际跳转共用 `MIUingTextIndex`，匹配跨行内元素、等价空白、大小写及UTF16范围。隐藏祖先下的文字不会被误搜。使用实际CSS和DOM，片段偏移不作为阅读锚点。
- 每个命中取前后50个Unicode码点，规范化空白，匹配摘要最长256字符；结果不写入书库文件。
- 复用现有 `ReadingPreview`，搜索期间暂停后台全书页数计数，退出后继续；主视图加一个辅助视图，最多两个WebView。被动预览没有书库位置回调。
- 输入300毫秒防抖，关键词最多256个UTF16字符。每章20秒超时，最多1000条；达到上限在列表顶部提示。大书首次搜索逐章扫描，可能耗时，完整扫描后结果才可点击；可关闭面板取消。没有宣称即时全文索引或实体设备性能提升。
- 取消使用任务owner保护，旧请求不会关掉新请求的预览；输入代际隔离旧结果。后台取消，回前台重建；布局变化完成旧回调，按新布局重试当前章节。
- PDF继续沿用已有按页搜索。固定版式、DRM等既有边界不变。

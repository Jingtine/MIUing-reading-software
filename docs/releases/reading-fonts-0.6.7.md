# 正文字体 · 0.6.7

界面文字使用 Android 系统字体；正文的字体选择独立控制，不要求界面换成 Apple 字体。上轮“Apple 字体尚未对齐”指正文原版字库，不代表应替换菜单、按钮等系统界面字体。本轮字体选择页的字体名称也统一使用系统界面文字，不使用所选正文字库渲染名称。

## 可用选择

保留原始（书籍字体）、衬线、无衬线、等宽，新增用户提供的四款完整字体：

| 显示名称 | 原文件 | 字节 |
| --- | --- | ---: |
| 不明体 | H-TTF-BuMing-R-2.ttf | 13,421,816 |
| 思源宋体 | SourceHanSerifSC-Regular.otf | 24,543,332 |
| 方正晶宋 | 方正晶宋.ttf | 3,501,844 |
| 京華老宋体 | 京華老宋体v3.0.ttf | 33,259,644 |

四个原文件合计74,726,636字节（约71.3MiB），原文件均完整保留，运行时保持全部已编码字符覆盖。只请求选中字库；无应用联网下载，沿用禁止书籍脚本、禁止网络和仅同源字体的阅读安全配置。每主题单独保存选择，重建后仍有效；加载字体后再以文字锚点恢复原段落。字体加载失败回退为可阅读字体，不阻塞后续翻页；后来的导航优先于尚未完成的字体加载。

旧 WebView 的 Chromium69 在实际 API26 测试中拒绝超过30MiB的单字体，京華原文件33,259,644字节触发限制（控制台明确报 OTS font size more than30MB）。原文件改放 `font-sources/kinghwa.ttf`，运行时使用三个互斥 Unicode 分片，分别6,627,128、18,173,088、8,765,932字节。三个分片并集覆盖全部39,575个已编码字符，每个字形的展开轮廓、横向和纵向度量均与原字库一致；未删除生僻字。生成脚本与覆盖报告随仓库保存，FontTools 仅为开发工具，不增加应用依赖。三个分片均在恢复位置前加载，使用短样本文字选择分片，不增加整章扫描。

书籍字体模式仍尊重 EPUB 的字体声明和内嵌字体；自选字库覆盖普通正文，但保留代码、数学、SVG、符号图标等已有保护范围。切回书籍字体还原发布者样式。PDF 固定版面不使用这套正文字体设置。

## 原版字体范围

本地原版 `FontPresets-zh_cn.plist` 列出苹方、宋体、楷体、圆体。原包没有这些字库文件，故这些实际字体尚未内置；没有将 Android 通用字体改名冒充它们。“原始（书籍字体）”指使用书籍自带排版，和“原版 app 的字库”是两件事。

四个用户文件保留原始版权元数据；思源宋体附 SIL OFL1.1 文本，其他三个没有随文件提供单独许可文本，不统一宣称开源。文件来源、摘要和许可记录见 `app/src/main/assets/fonts/PROVENANCE.txt`。

## 验证

基线实际复现字体 ID 保存后回退为 book、选择页缺少新增选项。接入后定向8/8（77.923s），涵盖四款实际 FontFace 加载、发布者普通文字覆盖、每主题持久化、重建、锚点可见及切回书籍字体。另通过字体加载失败回退和加载期间导航优先级用例；连同已有延迟发布者字体页数更新，共3/3（7.200s）。

一次独立代码审查指出，字体加载期间导航可能只保存了新锚点，却没有按最终字形重新定位。初始自然语言测试未产生足够的分页变化；用256个窄字母的段落明确触发重排，并检查实际文字范围可见性后，先复现目标4200仍上报但文字已经离屏。修复记录最新发布的文字来源，在字体完成时定位较新的导航目标，不恢复旧目标、不额外写入进度；字体相关3/3重新通过（12.592s）。修复前启动的设备回归作废，交付矩阵使用修复后的同一冻结包。

旧 WebView 修复前12/13，失败仅为京華单文件超过上限；分片后实际加载三片、锚点和延迟字体相关定向4/4通过（33.043s）。初期因中断遗留测试书和动画倍率造成的环境失败已单独诊断，清理模拟器生成的测试数据、还原倍率后重新验证，未改产品逻辑或放宽断言。

平板进一步暴露连续切换时的来源漂移：自动恢复位置的滚动事件可能在最后一帧后到达，被误当成用户滚动，清掉了保留的文字锚点。实际记录显示京華三片已加载，目标8000的文字横坐标2469却处在1600宽的视口外，页面首锚点退至4431。通过记录程序滚动的实际限幅后坐标，仅忽略对应自身事件，真实用户滚动仍重新记录位置。未放宽文字范围可见性断言；恢复、字体重排和后续翻页共同回归。

Core12/12、JVM几何1/1、应用及仪器包构建、两份渲染 JavaScript 语法检查均通过；Lint0错误、20条已有警告。最终冻结包86,771,139字节（约82.8MiB），SHA256：`4CAB5284B998CB8A629B3187F11DB972BB2DE3F3CFCF701810E8A24BD026F2CF`。包内字库与已验证输入一致，未包含重复的京華原文件。

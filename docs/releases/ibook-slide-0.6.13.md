# 0.6.13：iBook 风格平移

版本码20；compile/target API36、min API26。聚焦 EPUB/TXT 阅读动效，新增“主题与设置 → 翻页样式 → 平移”。默认仍为卷页。

## 实现

参考 Peyilo/libreadview 的 IBookSlideEffect，适配上层整页平移、底页四分之一幅度跟随与最高80/255遮光。前翻是当前页离开，后翻是上一页进入，正文不镜像；不照搬卷页的翻转坐标。点击与跟手拖动共用合成分支，拖动取消不写进度，提交只导航一次，跨章回到上一章末尾。样式选择持久化。

沿用既有两 WebView 的排版/预览/全书分页生命周期，各临时位图上限2,000,000像素，逐帧不创建位图、Paint或Shader。目标捕获失败直接恢复已经提交的正文；重建、退出、取消和快速输入释放快照。禁用系统动画时直接导航。

点击平移等待 WebView 的 `postVisualStateCallback`，再捕获目标帧。独立审阅指出仅等待两个动画帧不能确认 Chromium 已画好目标；新增可延迟确认的 WebView 测试先失败，再通过绘制确认修复。保留快照身份检查，防止迟到回调继续旧动画。

新增运行时依赖为0；没有切换文字排版引擎或引入 Expo/Rust。MIT 原文随 APK 分发。三个参考项目的源码、版本与适用性见[核验记录](../reference/reader-projects-2026-11-23.md)。

## 验证证据

核心解析16/16；JVM4/4；Node手势5/5；六份阅读脚本语法通过。常规/个人构建成功，lint 0错误、24警告（新增一项 Canvas KTX 写法建议）。

修复后的 Android16 手机针对翻页、手势、初始布局、整本分页和脚注共34/34通过，229.928s。清除增量打包空洞后，最终个人APK在1080×2400/420dpi手机窗口追加平移5/5（36.049s），在1600×1200/160dpi平板窗口追加5/5（34.919s）。初轮独立平板AVD的平移/旧卷页拖动/初始布局14/14（71.085s）通过；此后新增绘制确认用例，已包含在最终平板窗口5项中。

Android8（1080×1920/420dpi）最终个人包5/5通过（28.733s），最终常规包5/5通过（28.243s），均包含延迟绘制确认。初轮个人包的平移与旧翻页12/12（81.614s）、常规包平移4/4（29.475s）也通过；最终补验使用重新打包后的冻结APK。

截图为真实应用中的有意稀疏测试出版物，不是页面设计稿：[手机跟手中间帧](../previews/phone-slide-held-0.6.13.png)、[平板跟手中间帧](../previews/tablet-slide-held-0.6.13.png)，均已目视核对。非对称彩色标记还验证前后叠层、视差、阴影、文字方向、端点及回收；真实EPUB覆盖取消、提交、跨章、样式保存、重建、禁用动画和不超过两WebView。

这些是针对受影响功能的回归，未将0.6.12的完整95项套件声称为本轮全部重跑。没有实体设备帧时间、耗电或Apple原版逐帧测量，不能称为与原版完全相同。

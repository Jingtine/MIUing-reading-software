# MIUing 0.7.9 TXT 兼容与升级验证

版本 0.7.9 / versionCode 30，2026-11-25。

新导入 TXT 支持独立 CR、CRLF 和 LF 换行，修复章节合并及空行丢失。旧书保存分章版本，继续生成旧章节内容，避免进度、书签和笔记的位置因重分章而改变。备份恢复保留对应版本，重复导入不改变旧记录。本版不自动将旧批注迁移到新章节。

## 验证

- Android 16 模拟器先安装已发布的 0.7.8 常规版，实际导入 CR TXT，通过旧版书库接口保存进度、书签和笔记，导出旧版备份。使用 `adb install -r` 覆盖安装 0.7.9，核对章节 HTML 字节及定位记录一致，并恢复旧、新备份。
- 覆盖升级验证 1 项、TXT 兼容 3 项、备份回归 15 项通过。个人版随后覆盖安装通过，TXT 兼容 3 项通过，测试样本已清理。
- 核心 37 项、应用 JVM 10 项、lint 与两种 APK 构建通过。沿用原开发签名，证书 SHA256 为 `cb0e2882a892f869a04f0bdd5dee3c1f18265176f13a76ce11cde37c2e31c538`。
- 本轮未执行实体设备、Android 8、平板或阅读界面高亮可见位置验证。上述升级证据针对书库记录和实际生成的章节内容。

# 文字搜索定位 · 0.6.4

EPUB/TXT 点选章节搜索结果后，定位并临时标出该章首次匹配的文字。输入查询只更新结果，不移动正文；返回入口恢复搜索前的原文位置。

## 实现

- 选中的查询与输入中的查询分开保存。当前章的实际 DOM 文字索引决定目标 UTF-16 锚点，不使用 Android Html 转换后的偏移定位。
- 字面匹配支持跨行内元素、实体和 emoji，统一连续空白与不依赖地区的 Unicode 小写转换。搜索视图保留段落、块元素与 `<br>` 边界，避免把前后两段误拼成一个单词；虚拟边界及大小写扩展映射回真实正文偏移。
- 临时搜索标记与笔记范围一起分段绘制，交叠处同时保留两种范围信息，不嵌套标记或修改正文。原笔记记录不变；同样的标记在主题变更时复用节点。
- 旋转和继续调整字号保留当前阅读位置；返回、其他跳转或自然跨章移除当前搜索标记。关闭重开不保留查询。
- 没有新增依赖、权限、后台任务或跨章 DOM 缓存。原始书籍和笔记格式不变。开发包仍使用既有项目调试证书。

## 验证

首轮四项新用例在 0.6.3 全部失败，初版实现后与原有文字引擎合计 7/7 通过。一次独立审查指出块边界误拼、发现阶段空白规则不同、Unicode 大小写规则不同的问题；新增两项回归在修复前均失败，再统一修复。对存储锚点的断言等待实际异步桥回调，未降低目标锚点精度要求。

完整回归还暴露了界面测试选取结果的时序问题。通过临时事件日志与层级截图确认：部分坐标点击没有进入结果回调，描述标签是实际可点击按钮的子节点。最终测试点击明确标识结果的父按钮，验证弹窗确实关闭并作有界重试；返回后等待正文恢复再进行下一次搜索。保留真实触摸操作，未绕过应用跳转或改用静态结果。诊断日志和临时访问无障碍树的实验代码已移除。Android8 的对应定向用例连续三次通过。

核心 12/12、JVM 几何 1/1、开发包与测试包构建、两段 JS 语法检查通过；lint 为 0 errors、20 warnings。最终开发包使用 0.6.4/code11、target36/min26，大小 27,181,150 字节（约 25.9 MiB）；SHA256：`863554537df792c8ae4b6e413221a0ff53b4b9c434df1906618189b0d57ce7a1`。

## 保留边界

搜索列表仍为每章一项，点击定位首次匹配；逐项命中列表和上一/下一匹配尚未实现。章节发现沿用 Android Html 文本，遇到复杂 EPUB 隐藏内容或非常规样式仍可能与浏览器文字存在差别；若当前章找不到实际匹配，回退到章首。当前没有外部全文索引。

截图只核对 MIUing 当前界面可读性，不表示已完成与 Apple Books 的精确视觉验收；没有真机帧时间、堆内存或电量测量。

# 0.7.6 长篇文字书搜索

文字书全书搜索按章节显示结果，找到的条目可以立即打开。跳到原文后，剩余章节继续扫描，跨章导航会更新为已找到的结果。关闭搜索导航会回到搜索前的阅读位置。

## 缓存与定位

- 每本正在阅读的书在内存里保留最近一次完成的查询结果，最多 1,000 条。再次搜索同一词且排版一致时复用。改用其他书籍、调整窗口或字号、重建 Activity 后重新检查匹配。
- 搜索、分页和卷页共用临时预览。卷页手势可以优先使用预览，扫描稍后重试被打断的章节。换词、退出搜索或后台停止时，取消旧任务并释放预览。
- 界面在扫描时显示已找到的数量。阅读器加载时，跳转等到位置可用再启用。排版改变后，按章节和正文锚点重新定位同一条匹配，即使它在列表中的序号有变化。若这条匹配在新排版下消失，阅读位置保留，可从新结果重新选择。
- DOM 匹配、区分可见正文、中文子串和原文锚点仍由现有阅读器处理。分批返回思路参考 Foliate-js，许可见现有归属记录。本轮沿用现有依赖。 [GitHub 调研](../reference/roadmap-repositories-2026-11-25.md) · [搜索归属记录](../../third_party/foliate-js/SEARCH-ADAPTATION.md)

## 性能测量

同一个 Android 16 手机模拟器，使用测试生成的 24 章 EPUB，每章 260 段填充文字，首章与末章各有一个命中。计时从输入查询到 UI 看到结果，包含 300 ms 输入防抖和自动化轮询。测量用于对比同一测试场景，真机性能另行验证。

| 指标 | 0.7.5 | 0.7.6 首轮实现 |
| --- | ---: | ---: |
| 首次第一条结果出现 | 1.248 秒 | 1.294 秒 |
| 首次全书搜索完成 | 5.225 秒 | 4.953 秒 |
| 同词重复搜索完成（两次） | 5.097、5.166 秒 | 1.200、0.959 秒 |

0.7.5 的第一条结果需等待首次整书扫描结束才可打开。0.7.6 的回归用例在整书扫描结束前点开首条，并验证末章结果加入后能继续跳转。该轮记录的应用进程 PSS 在两版间有重叠，且不含独立 WebView 渲染进程，暂无法据此判断总内存变化。

最终包在 Android 16 手机回归中首次扫描用时 5.409 秒，两次同词重复搜索分别为 1.179 秒和 1.520 秒。该次回归与 Android 8 模拟器并行，单独列出以保留测量条件。

## 发布验证

- Android 16 手机窗口常规包通过 16 项搜索、原文跳转与 PDF 搜索回归。Android 8 手机窗口常规包通过 15 项搜索与原文跳转回归。
- Android 16 平板窗口（1600 × 1200）个人包通过 3 项测试，覆盖搜索期间跳转、旋转后续读与字体变化时的缓存失效。
- 核心检查 25 项和 JVM 测试 10 项通过。Android Lint 0 错误、24 项警告。
- 两包为 versionCode 27，核对了原开发签名、正文字体和运行时脚本。常规包排除两款个人字体。APK 与摘要位于本地 `dist/0.7.6/`。

# 文字阅读与主题面板 · 0.5.0

本轮重点为 EPUB/TXT。按固定 iOS18 官方界面参考重做“主题与设置”：标题/关闭、字号、翻页和外观、细亮度条、六张主题卡片、底部自定义。详细字体和布局移入独立页面。参考链接及近似实现边界见 [参考依据](reference/theme-panel-reference.md)。

## 阅读行为

- 每主题独立保存字体、粗体和布局，首次升级只把旧的全局排版迁入先前选中的主题。无新增依赖或权限。
- 自定义使用草稿：“完成”保存；返回时提示放弃或继续编辑；重建保留尚未提交的草稿。“还原主题”仅重置当前草稿，完成后生效。
- 书籍原字体、Android 衬线/无衬线/等宽字体实际作用于正文，覆盖 EPUB 自带段落及行内 `!important` 字体。回到原始设置恢复书籍原样式；代码、数学、SVG 和常见符号字体避免强制覆盖。
- 行距、字符/词间距、页边空白和两端对齐由“自定义布局”启用；关闭时保留草稿中的数值。外观支持浅色、深色、匹配设备，亮度可恢复系统设置。
- 连续切换排版保留逻辑文本锚点，避免每次重新捕获页首而逐渐向前漂移。首次连续配置保留待恢复的目录片段或进度，过期布局回调不会覆盖新配置。
- 小屏各子页面使用独立滚动状态；从主面板新开自定义回到顶部，字体页返回仍保留正在编辑的位置。手机底部面板和宽屏有界面板均可滚动。

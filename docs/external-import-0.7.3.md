# 0.7.3 系统文件接入

- 文件管理器“打开方式”、其他应用单本/多本分享，支持 VIEW / SEND / SEND_MULTIPLE / ClipData。
- 单本导入后阅读，多本完成后回书库并汇总。相同原文件摘要去重，保留已有批注与进度。
- ViewModel 持有统一书库及串行队列，旋转不取消或重复导入；等待备份时也记录待处理状态。进程重建时提示重新选择中断的文件，不重试失效授权。
- 外部 URI 只读取一次，先保留私有副本，再按最多4096字节文件头、文件名和 MIME 识别。已有完整解析器继续校验文件。复制上限1GiB，识别后的转换格式仍限64MiB；EPUB内部资源/TXT等原有限额保留。
- 仅接收 content URI；不注册网络地址、file URI或全部MIME通配符。支持已知七格式及常见通用二进制MIME，来源应用标注其他MIME时可能不显示打开入口，可使用应用内文件选择器。
- 有效批次最多64个不同URI；队列最多64批。权限失效、坏文件分别报告，不阻塞后续文件。消息显示与队列处理分离。

参考 [Readium Test App manifest](https://github.com/readium/kotlin-toolkit/blob/develop/test-app/src/main/AndroidManifest.xml) 的独立 VIEW/SEND 路由思路；本轮代码基于已有 AndroidX 与导入器编写，没有复制上游源码或增加运行时依赖。

## 验证

独立审查发现的排队中断标记和错误扩展名大小限额问题，均已用失败测试复现并修复。测试提供器仅在测试APK提供合成正文，无用户文件访问；验证冷启动、热启动分享、单次读取源、旋转、重复导入与批注保留、多本及权限失败。另有72MiB EPUB错误命名为MOBI的回归。

Android16最终46项通过（94.920秒）；个人版1600×1200平板窗口10项通过（19.029秒）。Android8最终结果与安装包核对见下方交付记录。核心25项、JVM4项通过，lint 0错误、24警告。

保留边界：不新增书源、云下载、DRM解密或压缩包书籍格式。系统终止进程时，不保证恢复未完成批次，需要重新分享/选择；已完成私有复制的书籍不依赖原提供器。不同厂商文件管理器和聊天应用仍需实体设备验证。

最终 Android8 回归：37项通过（28.966秒），运行日志 `.tools/external-api26-verified.log`。旧排版测试现等待实际段落可见，测试轮询索引改为Main线程，避免与AtomicFile写入并发恢复备份；产品代码无此并发读取路径。

# 文字阅读控件参考

基准为固定的 [Apple iPhone iOS18 阅读指南](https://support.apple.com/en-gb/guide/iphone/iphc1af7c57/18.0/ios/18.0)，本地已保存该版本网页用于核对。

已下载并查看原图 `Art/S1001_bksBookPage_iPhone.png`（854×1134），[公开图片](https://help.apple.com/assets/683A54F5227CBBDB98051B96/683A54FC545676DF600F97D4/en_US/d95d30419f70871b68fedb41df1bbd74.png)。原图显示：右上角关闭、顶部居中的本章剩余页数、底部居中的阅读位置、右下角阅读菜单；正文没有常驻的目录/主题/搜索整排按钮和大进度条。左上还有返回先前位置入口。

本轮据此调整 EPUB/TXT 的关闭、状态和阅读菜单位置。菜单承载现有目录、主题、搜索、书签、高亮笔记及章节进度。开关工具采用覆盖层，正文视口保持固定，避免工具显隐触发重新分页。

区别与待核对项：

- MIUing 显示按当前视口计算的**本章**页数，宽屏双栏视口计为一页；滚动模式显示本章百分比。尚未计算整本书页码，不将章节数或估算值伪装成全书页数。
- 指南证实目录、搜索和主题等通过阅读菜单进入，但未取得同版本展开菜单截图；展开菜单的尺寸、行距、图标和阴影是 Android 近似实现。
- 原图左上“返回先前阅读位置”、方向锁定、分享等仍需后续实现与对照。精确 Apple 字体、整体排版和 iPad 原版尺寸也尚未全部核对。
- 本轮不调整 PDF 的阅读控件组织。原版图片只用于本地对照，不纳入 APK 或 Git；仓库中的运行截图均来自 MIUing。

# 阅读体验对齐：0.2.0

2026-11-18，在已推送的 d4148a9 开发版基础上继续实现。

## 本轮变化

- 解析 EPUB3 nav 与 EPUB2 NCX，保留嵌套层级、显示名称和段落片段；合法的外部 DTD 声明只移除不访问，仍拒绝内部 DTD/实体。
- 无可点击目录项时继续尝试 NCX 或章节列表，避免只显示不可用分组。
- EPUB/TXT 记录 UTF-16 正文偏移；调整字号、排版或重建页面时恢复原文，旧记录继续兼容。
- 新高亮记录选区起止位置，能区分重复文字并跨段落恢复，保留原文段落结构。
- 笔记支持修改内容与前往原文，取消编辑会清空暂存选区。
- 增加行距、页边距、字间距和应用窗口亮度设置，不修改系统全局亮度。
- 阅读脚本拆为应用内资源，CSP、资源白名单及禁用书内脚本保持生效。

## 验证与审阅

核心测试现有 12 项，增加 EPUB3/NCX 层级、转义片段、目录降级回退测试。Android 仪器测试现有 6 项，增加旧书库记录兼容、正文锚点、排版变化/重建、段落边界、重复文本与跨段落高亮、目录后切换模式和取消笔记编辑的覆盖。

实际执行命令与结果在实施计划末尾记录；不能把上面的测试覆盖列表当作未经执行的通过声明。

独立审阅指出的旧目录片段重跳、空选区状态残留、纯分组目录阻止回退与偏移边界问题均已修复并增加回归场景。额外验证了正文前存在 style/script 时元素选区的偏移计数。

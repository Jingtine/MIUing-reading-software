# 阅读页视觉对照

继续执行原版优先指令，本轮直接对照已保存的 iOS18 官方阅读页截图 `.tools/apple-books-reading-ios18.png`，来源见 docs/reference/reader-chrome-reference.md。

校准 EPUB/TXT：返回原文入口移至左上角，显示小型反色圆形返回图标及来源章节；右下菜单采用圆角方形底与两横线/三点图形；顶部/底部状态降低至次级文字层级。顶栏状态保持居中，右上关闭与正文视口尺寸不变。继续显示真实的本章页数，不伪造原版截图中的全书页码。

对无自带字体的文字核查系统字体回退。若当前回退为无衬线，则仅设置 WebView 的标准回退字体为 serif；书籍 CSS 指定的字体仍优先，不将 Apple 专有字体或原版具体字号作为已复现。

选择原生 Compose 图形绘制菜单图标，不复制原版位图，不增加依赖或字体包。返回来源沿用既有历史数据，文本暂用“第 N 章”，全书页码独立后续完善。PDF 与展开菜单结构不变。

验收：真实跳转后返回按钮位于左上且不与关闭/状态重叠；显隐和返回不改变正文视口，原文锚点恢复；实际字体测量确认无样式回退与发布者覆盖；手机/平板截图目视对照与相关回归。

# 正文字体与界面字体

用户明确区分非正文界面跟随 Android 系统、正文提供内置字体，并提供四个本地字体文件。沿用现有分层：Material/Compose 默认系统界面字体；字体选择只更改 EPUB/TXT 正文。字体列表的名称也使用系统界面字体。书封与书名已有展示样式不在本轮重设。

正文保留书籍字体、衬线、无衬线、等宽四个现有选项，增加不明体、思源宋体、方正晶宋、京華老宋体。稳定 ID 分别为 buming/source-han-serif/fz-jingsong/kinghwa，独立目录管理名称与文件，避免设置页、存储校验和渲染各写一套。用户给的字库以完整字符覆盖内置，无网络下载，无新应用依赖；切换仅加载选中字库，保留书籍字体选项与每主题设置。

原 app 简体中文 FontPresets 实际列出苹方、宋体、楷体、圆体，但 Books.app 未提供这些字体文件；本轮不将 Android 通用字体冒名为这些原版字库。实际原版字库尚缺，不声称已内置。

实现选择：完整字符覆盖的资产内置，离线即用，四个原文件合计约71MiB；不选择联网下载（不符合离线内置）或删除字符（可能丢失生僻字）。验证发现旧 Chromium69 有30MiB单字体限制，京華原文件超过限制，因此完整原文件保留于 font-sources，运行时使用三个 Unicode 分片。三个分片并集包含全部39,575个已编码字符，每个字符的轮廓和横纵度量与原文件逐项校验一致。其余三款原样内置。通过同源受限 WebViewAssetLoader 提供字体，不放开网络、文件或内容访问。加载选中字库完成后再恢复来源锚点，过时加载不能覆盖后来导航；切回书籍字体还原发布者样式。

验收：四款选择可实际加载字体而非仅改名称；保存/重建保持选择；切换保持原文锚点；切回原始还原发布者字体；原有界面不随正文字体变化。保留字体版权元数据与可取得的授权文本，不对未附许可的字体宣称开源。

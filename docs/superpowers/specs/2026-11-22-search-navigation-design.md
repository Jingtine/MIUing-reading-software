# 本章逐项搜索导航 0.6.11

沿用用户持续完善文字阅读与接近原版的指令，本轮补齐选中章节后逐项查看匹配的能力。界面和平台沿用现有 Android Kotlin/Compose 与受限 WebView，不增加依赖。继续在已有功能分支实施和推送。

采用真实 DOM 匹配序号定位，不采用 Android Html 发现阶段的偏移；后者与实际显示内容可能不同。全书后台逐项索引涉及额外渲染调度，本轮暂不引入，搜索列表仍按章节显示，上一处/下一处明确限于当前章。这是本轮实施范围，不是用户对原版等价性的确认。

点击已有章节结果进入第一处匹配，阅读页出现“本章 n / 总匹配数”、上一处/下一处和关闭搜索入口；边界按钮禁用，加载期间禁用跳转。关闭搜索只移除临时标记，保持当前原文。逐项移动不新增历史记录，返回入口始终可恢复进入本次搜索前的位置。

匹配保留字面标点、跨行内元素、等价空白与 Unicode 大小写规则。遍历匹配时只保存所选范围与总数，不保留所有匹配对象或批量包装全部结果。当前临时标记继续与笔记分段叠加，源文本和 UTF-16 锚点不变。旋转、字号改变保留当前原文和选中序号；自然跨章和其他跳转清除搜索导航。

不新增 PDF 功能，不改变私人字库分发策略，不宣称全书逐项索引或原版视觉完全等价。界面控件叠在现有阅读工具区域，正文尺寸不随搜索控件显隐变化。

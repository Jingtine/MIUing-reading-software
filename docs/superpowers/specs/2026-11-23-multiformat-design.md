# 复用开源解析器，扩展常见电子书导入

用户要求整合开源阅读能力，明确优先 MOBI / AZW / AZW3、FB2。沿用此前授权的持续实现、现有工作区及功能分支推送方式。功能组织和视觉继续向 Apple Books 靠近。

## 方案选择（本轮实现选择）

复用 Foliate-js 的 MIT 格式解析模块，导入时转换为应用私有的标准 EPUB，再接入现有阅读器。另一条路线是整体替换为第三方渲染器，需迁移已有锚点、批注、脚注、分页和翻页，不适合这轮格式扩充。现有参考库没有同时提供本轮所需四种格式，因此引入实际支持这些格式的 Foliate 模块。

保留原文件及其 SHA256 去重身份、原格式标签、书名/作者/封面、目录、内链、图片、CSS和可用的嵌入字体。解析结果以章节和资源输出为标准EPUB；用统一目录、搜索、书签、高亮、脚注、字体、分页、进度恢复和动效。不是将几套完整应用并排塞入菜单。

范围为未加密的 MOBI7、KF8（含MOBI/KF8双格式）、常见AZW/AZW3封装和FB2。AZW是扩展名，不保证其内部为MOBI/KF8；DRM、KFX、Print Replica 明确报不支持。不解密，不把更名文件当成支持格式。Word、RTF、漫画压缩包本轮不做。

## 模块边界

- `third_party/foliate-js/`：固定上游提交的 mobi.js、fb2.js、fflate.js，保留原始源码，不自行重写这些解析器；许可置于APK assets/licenses。
- `tools/import-converter/`：转换适配代码、Chrome69兼容层和固定版本esbuild构建依赖。产物为离线IIFE脚本，常规Gradle构建直接使用已提交产物。
- `BookFormatImporter.kt`：只在导入时启动隔离的临时WebView；本地资源映射、限时、协程取消、桥接和释放。不会加载书内脚本或导航至外部页面；阅读时不保留转换WebView。
- `ConvertedBookWriter.kt`：接收有界二进制分块、验证生成文件名与元数据、输出标准EPUB，失败/取消清理中间文件。
- `LibraryStore.kt`：原文件仍为source；转换格式读取同目录normalized.epub。旧EPUB/PDF/TXT数据无需迁移。

## 约束

API26–36，手机和平板；不新增网络权限、原生NDK引擎或在线转换服务。原文件64MiB上限用于新增转换格式，现有格式限制保持原样。转换章节上限2000、目录项2000、单资源16MiB、总输出256MiB，文本总量32MiB，转换限时60秒；失败给出具体原因，取消不得留下书库记录。固定上游版本、构建依赖与LICENSE，产物可重建。

桥接只接受生成的安全文件名和有界Base64块。转换文档保持惰性，不挂入运行页面；主动内容、事件处理器与外部资源移除，资源本地化，内链和目录锚点写为标准EPUB路径。非线性注释正文进入manifest但不进入主阅读顺序。

导入完成前不发布书库记录。重新启动后直接读取私有EPUB，不依赖转换页面或原始下载URI；原文件移除不影响阅读。若私有转换文件丢失，明确提示重新导入，不覆盖或重置已有记录。

## 验证

真实格式字节验证导入/阅读，而不是只测试扩展名列表。MOBI覆盖未压缩、PalmDOC、HUFF/CDIC及KF8样本（可获得合法样本时）；FB2覆盖中文、图片、层级目录、内链与注释。已有EPUB/PDF/TXT路径回归。测试DRM/错误封装/损坏数据、路径/大小限额、失败清理与取消，原文件保留、去重、重开、搜索/批注和翻页。在Android16手机/平板窗口及Android8旧WebView运行，若某变体缺乏可用样本，逐项报告验证边界。

# 文字搜索结果定位

沿用已经确认的原版优先、文字阅读优先、轻量和维护清晰的要求。本轮修复点搜索结果只到章节开头的问题。

## 选择与范围

复用当前章 DOM 文字索引，在实际显示的文字中定位该章首次匹配；不把 Android Html 转换后的偏移当作书签锚点。另一方案是直接使用 WebView 原生查找，但其异步滚动会与初始分页和返回来源竞争；也不为此增加全书 HTML 解析库。

结果列表沿用每章一项，点击后定位并临时标出首次命中。关键词按字面、不区分大小写匹配；空白连续段允许等价匹配。跨行内元素、HTML 实体和 UTF-16 字符使用真实 DOM 范围。无实际匹配时保留章节开头回退。

输入查询只更新结果，不移动正文或改变返回来源。主动跳转保存来源；返回、其他跳转和关闭重开清除当前搜索标记。Activity 重建保留搜索标记和当前真实阅读位置；自然翻页不跳回命中位置。搜索标记只在当前会话内显示，不存成笔记，不修改原书。

将单一搜索范围与笔记范围一起分段绘制，重叠时搜索颜色优先，文字与笔记记录保持不变。相同范围下调整主题仍复用节点和选区。仅保存当前章索引，无新增依赖、权限或后台服务。

## 验收

- 在手机和平板的分页/滚动模式，首次命中处于可见区域；搜索跨行内元素、实体、emoji 及包含正则标点的字面文本。
- 原有笔记与临时标记重叠不改变正文、偏移和笔记；无命中或清空时移除临时标记。
- 输入关键词不移动正文；同章/跨章结果定位可返回原锚点；旋转和字号调整保持当前阅读位置。
- API36 手机/平板窗口、API26 回归；继续记录原版精确视觉和真机流畅性尚未验收的限制。

每章多项命中列表与上/下一匹配不在这一轮范围，继续记录为后续工作。

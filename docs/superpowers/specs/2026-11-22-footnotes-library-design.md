# 脚注就地查看与书库校准 0.6.12

用户接受先改善脚注体验和书库视觉。本轮沿用已有 Kotlin/Compose、受限 WebView、功能分支及推送授权。实施选择由构建者负责，不增加依赖或字体，不更改导航结构。

## 脚注

识别 EPUB noteref/doc-noteref，以及同章指向明确 footnote/endnote 目标的链接；普通链接保留已有跳转。链接以当前章节实际文件 URL 解析，支持同章片段、跨章以及不在 spine 中的尾注文件。仅访问书籍根目录内的本地资源。

采用当前阅读 WebView 内的隔离弹层，避免增加第三个 WebView，继承当前正文字体、字号及主题。原生 IO 侧复用现有受限 XML 解析器提取脚注，输出有限的段落、列表和强调标签；删除活动内容、URL属性及回链。没有脚本、网络或外部实体能力。展示基本富文本，图片、复杂数学/交互脚注和畸形 HTML 不作为新增兼容承诺。

弹层位于正文流之外，不改源文本、正文尺寸、锚点或全书计数。支持关闭、遮罩和系统返回；关闭恢复来源控件与焦点。旋转/重排关闭弹层并保留原文。加载失败显示明确提示；可导航的 spine 目标提供前往原文入口，回用现有来源历史。

单次内容上限32K字符，序号/文档所有权守卫屏蔽过期异步结果。普通链接不能因文件名类似footnote而被误判。

## 书库

目前封面统一裁剪、主页书名使用衬线UI字体、网格缺作者信息，且从阅读返回可能丢失书库模式。本轮保留完整封面比例并底边对齐，适度校准阴影和间距，统一两行书名、一行作者和真实阅读状态。UI继续跟随Android系统字体。

继续阅读卡片突出封面与标题，显示真实章节或PDF页状态，不把章内百分比冒充全书进度。书卡整块可打开，选项仍独立；列表保持同一套封面和元信息。返回书库保留标签、筛选、显示方式及滚动位置。网格按实际内容区自适应，手机约两列、常见平板更多列，不固定套用设备类型。

这是基于既有配色和 Apple 书库组织方式的校准，不宣称像素复刻；当前没有同版本完整书库截图可作逐像素尺寸依据。原版参考包/网页图片、私人字库与个人APK不纳入Git。

## 验收

脚注覆盖同章、跨文件、非spine、误判、异常、关闭不移动、系统返回、重排、字体、普通链接及文本/页数不变。书库覆盖横竖封面完整显示、长标题、整卡点击和返回状态。最终核心/JVM/JS/lint与手机全量、平板/Android8相关回归，版本19/0.6.12，冻结两种字体构建并核对资产、签名、提交推送。

参考：[W3C EPUB语义词汇](https://www.w3.org/TR/epub-ssv-11/#sec-notes)、[Apple书库组织](https://support.apple.com/en-is/guide/iphone/iphab219b91/ios)。脚注用noteref/footnote语义做识别；Apple指南支持网格/列表和藏书组织，未据此推定未知的像素参数。
